## 2. 当前代码基线（截至本次更新）

### 2.1 入口：`Game`
- 文件：`Scripts/Tetris/ChessBoardSet/Game.cs`
- 主要职责：
  - 持有并初始化棋盘（`ChessBoard`）、当前活动方块数据（`CurrentPiece`）、方块生成器（`PieceSpawner`）、方块控制器（`PieceController`）。
  - 作为主循环入口，在 `Update` 中处理输入、驱动方块下落。
  - 负责方块落地后的完整流程：写入棋盘数据、实例化落地方块、消行、生成新方块。
  - 负责接入 UI Toolkit 计分界面（`ScoreUI`），在消行后更新分数显示。
- 关键方法：
  - `Awake()`  
    - 创建 `ChessBoard`（传入棋盘宽高），`CurrentPiece`，以及 `PieceSpawner` / `PieceController`。  
    - 初始化 `settledViews[width, height]` 用来记录每个格子的落地方块 `RectTransform`。
  - `Start()`  
    - 用 `PieceSpawner.SpawnPiece(...)` 生成首个方块。  
    - 绑定 `PieceDebugView` 以便在 Inspector 中实时看到当前方块逻辑坐标。  
    - 初始化分数 `currentScore = 0`，并通过 `scoreUI.SetScore(0)` 同步到 UI。
  - `Update()`  
    - 调用 `pieceController.HandleInput(...)` 处理左右移动、旋转、是否加速下落。  
    - 根据是否按住↓键，计算实际下落间隔，并调用 `DropDown(isFastDrop)`。
  - `DropDown(bool isFastDrop)`  
    - 使用 `GameConst.DropInterval` 控制自然下落速度，按帧积累 `deltaTime`。  
    - 到时间后调用 `pieceController.TryMoveDown(...)`：  
      - 如果可以下落，则更新逻辑坐标 + UI 坐标。  
      - 如果不能下落（触底或撞到已落地方块），调用 `OnPieceLanded()`。
  - `OnPieceLanded()`  
    - `chessBoard.SetBoardStatus(currentPiece)`：把当前活动方块写入棋盘 `cells`。  
    - `RenderSettledPiece()`：把每一个单格复制为静态方块，加入 `settledPiecesRoot`，并登记到 `settledViews[x,y]`。  
    - `ClearLines()`：遍历所有行，清除满行，并让上方所有行整体下落（数据 + 表现）。  
    - `SpawnActivePiece()`：生成下一块。

### 2.2 棋盘：`ChessBoard`
- 文件：`Scripts/Tetris/ChessBoardSet/ChessBoard.cs`
- 当前结构：
  - 字段：
    - `boardWidth`, `boardHeight`：棋盘宽高。
    - `int[,] cells`：棋盘占用矩阵，`0` 表示空，`1` 表示已占用。
  - 构造：
    - `ChessBoard(int width, int height)`：调用 `InitBoard` 初始化数组全部为 0。
- 关键方法：
  - `IsValidPosition(Vector2Int piecePosition, Vector2Int[] points)`  
    - 对给定锚点 + 方块所有相对点坐标进行边界检测和占用检测。  
    - 如果出界或对应格子已被占用，则返回 `false`。
  - `SetBoardStatus(CurrentPiece currentPiece)`  
    - 将当前方块所有格对应的 `cells[x,y]` 置为 1，用于后续碰撞和消行判断。
  - `IsRowFull(int y)`  
    - 遍历一行，如果全为 1，则认为该行为满行。
  - `ClearRow(int y)`  
    - 将某行全部重置为 0。
  - `ShiftRowsDown(int startY)`  
    - 从 `startY` 行开始，将其上的每一行整体下移一格，最顶行清 0。  
    - 用于消行后“上方整体下落”。

### 2.3 方块数据：`PieceType` / `PieceData` / `CurrentPiece`
- 文件：
  - `Scripts/Tetris/Enums/PieceType.cs`：定义 7 种标准俄罗斯方块枚举（I, O, T, S, Z, J, L）。
  - `Scripts/Tetris/Utilities/PieceData.cs`：  
    - 使用 `Vector2Int[][]` 保存每种方块在 4 个旋转状态下的局部坐标点。  
    - 提供 `PieceData.GetCells(PieceType type, int rotation)` 作为统一入口。
  - `Scripts/Tetris/Piece/CurrentPiece.cs`：  
    - `PieceType Type`：当前方块类型。  
    - `int Rotation`：当前旋转状态（0~3）。  
    - `Vector2Int[] Points`：当前旋转状态下，4 个小格的相对坐标。  
    - `Vector2Int Position`：当前方块锚点在棋盘上的逻辑坐标。

### 2.4 方块生成：`PieceSpawner`
- 文件：`Scripts/Tetris/Piece/PieceSpawner.cs`
- 职责：
  - 负责生成新方块、刷新方块相对坐标 UI、刷新锚点 UI 位置。
- 关键方法：
  - `GetRandomPieceType()`  
    - 使用 `Random.Range(0, 7)` 在 7 种 `PieceType` 中随机选择。
  - `SpawnPiece(PieceType type, int rotation, CurrentPiece currentPiece, RectTransform baseSquareTransform, int boardWidth, int boardHeight)`  
    - 初始化 `CurrentPiece.Type / Rotation / Position / Points`。  
    - 默认出生位置：`(boardWidth / 2, boardHeight - 2)`。  
    - 调用 `RefreshPiecePoints` 和 `IndexToUIPosition` 同步 UI。
  - `RefreshPiecePoints(Vector2Int[] points, RectTransform baseSquareTransform)`  
    - 根据 `points` 更新每一个子格的 anchoredPosition（局部坐标）。
  - `IndexToUIPosition(CurrentPiece currentPiece, RectTransform baseSquareTransform)`  
    - 根据 `currentPiece.Position` 更新整块方块的 anchoredPosition（根节点）。

### 2.5 方块控制：`PieceController`
- 文件：`Scripts/Tetris/Piece/PieceController.cs`
- 职责：
  - 只负责“活动方块”的输入响应和移动/旋转合法性判断。  
  - 不直接改棋盘，只通过 `ChessBoard.IsValidPosition` 判定是否合法。
- 关键方法：
  - 构造：`PieceController(PieceSpawner pieceSpawner, ChessBoard chessBoard)`  
    - 通过手动依赖注入持有棋盘和生成器。
  - `HandleInput(CurrentPiece currentPiece, RectTransform baseSquareTransform)`  
    - 处理键盘输入：左（←）、右（→）、旋转（↑）、加速下落（↓）。  
    - 内部调用 `TryMoveHorizontal` 和 `RotateClockwise`，并在成功移动后刷新 UI。
    - 返回值：是否按住 ↓（用于控制 `DropDown` 的下落速度）。
  - `TryMoveHorizontal(...)`  
    - 先预判下一步位置是否有效，如果有效则更新逻辑坐标和 UI。
  - `TryMoveDown(...)`  
    - 向下移动一格的模拟版，与上类似。
  - `CanMoveDown(CurrentPiece currentPiece)`  
    - 只做检测，不改状态，用于锁延迟等逻辑（当前简化版中未强依赖）。
  - `RotateClockwise(CurrentPiece currentPiece)`  
    - 计算下一旋转状态，取得对应 `Points`，通过棋盘验证后才真正确认旋转。

### 2.6 落地方块与消行表现
- 文件：`Scripts/Tetris/ChessBoardSet/Game.cs`
- 相关方法：
  - `RenderSettledPiece()`  
    - 对当前活动方块的 4 个子格，逐个 `Instantiate` 出静态方块，挂到 `settledPiecesRoot` 下。  
    - 使用逻辑坐标 `(x, y)` 映射到 UI `anchoredPosition`，并记录到 `settledViews[x,y]`。
  - `ClearLines()`  
    - 从下到上遍历所有行，调用 `chessBoard.IsRowFull(y)` 检测满行。  
    - 对于满行：  
      - `ClearVisualRow(y)`：销毁该行所有静态方块 GameObject。  
      - `chessBoard.ClearRow(y)`：棋盘数据清空。  
      - `ShiftVisualRowsDown(y + 1)` 与 `chessBoard.ShiftRowsDown(y + 1)`：上方整体下移一格。  
      - 使用 `y--` 保证不会漏检连续可消的行。

### 2.7 积分与 UI Toolkit：`ScoreUI` + `ScorePanel`
- 文件：
  - `Assets/UI Toolkit/ScorePanel.uxml`：  
    - 使用 UI Toolkit 定义分数界面结构（`VisualElement` + `Label`）。  
    - 当前包含：根容器 `score-root`，分数字 `scoreLabel`。
  - `Assets/UI Toolkit/ScorePanel.uss`：  
    - 使用 USS 控制布局与样式：  
      - `score-root`：占满整个 UIDocument 面板。  
      - `score-text`：右上角大号白色文字显示分数。
  - `Scripts/Tetris/UI/ScoreUI.cs`：  
    - 从 `UIDocument` 的 `rootVisualElement` 中查找 `name="scoreLabel"` 的 `Label`。  
    - 提供 `SetScore(int score)` 方法用于更新显示文字。
  - `Game.cs` 中：  
    - 新增字段 `public ScoreUI scoreUI; private int currentScore;`。  
    - 在 `ClearLines()` 中统计 `linesCleared`，使用 `GameConst.ScorePerLine` 计算本次得分，并通过 `scoreUI.SetScore(currentScore)` 更新 UI。

## 3. 当前已知问题 / 局限

1. **未实现游戏结束判定**  
   - 当方块堆到顶部时，尚未触发 Game Over 状态或停止生成新方块。
2. **未实现最高分与持久化**  
   - 目前只有本局分数，未记录历史最高分，未使用 `PlayerPrefs` 等持久化机制。
3. **UI 布局仍为简化版**  
   - 棋盘和分数界面尚未做“左侧游戏、右侧竖排分数信息”的正式布局。  
   - 掌机风 UI 皮肤尚未接入（目前为测试用方块素材）。
4. **状态机未落地**  
   - 暂未引入显式的 `Init / Running / Paused / GameOver` 状态机，开始与结束流程相对粗糙（进入场景即开始，结束时无结算界面）。
5. **输入系统只支持键盘**  
   - 仅支持 PC 键盘方向键操作，未针对触屏/虚拟按键做适配。
6. **按钮系统尚未实现**  
   - “开始游戏 / 结束游戏 / 再来一局”等按钮计划使用 UGUI（非 UI Toolkit），目前尚未接入。

## 6. 验收标准（按阶段）

### 阶段 A：核心闭环（当前已基本达成）
- 方块按时间下落，触底后不再穿透。  
- 新方块能正常持续生成。  
- 棋盘占用数据（`cells`）与画面显示一致。  
- 行消除后，上方方块整体下落无错位。

### 阶段 B：基础可玩
- 左右移动和旋转有明确边界与碰撞保护。  
- 错误操作（越界、撞到已落地方块）会被拒绝，不会抛异常或出现卡死。  
- 基础分数系统工作正常，消行数与得分增长对应正确。

### 阶段 C：完整规则与体验（规划中）
- 存在可见的当前分数与最高分，且最高分可跨局保留。  
- 方块堆到顶部时能触发 Game Over，停止游戏，并有清晰提示。  
- 存在“开始游戏 / 再来一局”等按钮，状态切换顺畅。  
- WebGL 版本在目标平台（浏览器）上运行稳定。

## 7. 术语与约定（实现侧）

- 棋盘坐标：`(x, y)`，原点在左下角（`y` 向上为正）。  
- `cells[x, y]`：`0` 表示空，`1` 表示已占用（后续可扩展为不同类型编码）。  
- 逻辑坐标为唯一数据源，UI 坐标始终由 `逻辑坐标 * CellSize` 映射得到。  
- 渲染刷新触发时机：**逻辑状态变更后立即刷新 UI**，渲染层不自行推演逻辑。
